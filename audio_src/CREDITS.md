# Audio credits

## Isolated letter sounds (`audio_src/ipa/*.ogg`)
Human recordings of IPA sounds from Wikimedia Commons ("IPA chart with audio"), mostly by Peter Isotalo and other contributors.
Licence: **CC BY-SA 3.0** (one file public domain) - https://creativecommons.org/licenses/by-sa/3.0/
Each file title is in `ipa_sources.txt` (look it up on commons.wikimedia.org under `File:<title>` for the author).
Diphthongs and r-coloured vowels (ai, oa, igh, ow, oi, ar, or, air, ear) are short crossfaded blends of these recordings - an approximation until a teacher records them with `tools/recorder.html`.

## Words and sentences
Generated with the Piper neural text-to-speech engine (MIT licence, https://github.com/rhasspy/piper) using the **LJSpeech** voice
(`en_US-ljspeech-high`), trained on the public-domain LJ Speech dataset. No attribution required; credited here anyway.
Placeholder quality: replace with the teacher's recorded voice via `tools/recorder.html` where possible.
